# TORA Luxury Collective

This project represents a high-end, cinematic e-commerce experience for **TORA**, a brand specializing in powerful, handcrafted pottery inspired by the spirit of the tiger.

## Brand Identity & Design Prompt

If you want to recreate or expand upon this specific aesthetic, use the following comprehensive prompt:

### The TORA Cinematic Prompt:
"Create a high-end Next.js e-commerce application for a luxury brand named **'TORA'**. The theme is **'Cinematic Power'** inspired by the tiger. 

**Core Visuals:**
- **Color Palette:** Pure black background (`#000000`) with high-vibrancy 'Tiger Orange' (`#FF6600`) for primary accents and glows.
- **Background:** Implement dynamic, moving light streaks (Tiger Stripes) that flow across the dark canvas using CSS animations.
- **Header:** An ultra-slim, transparent glass-morphism header. Centered is a large, iconic 'TORA' serif logo (Playfair Display) that serves as a hidden entry point for admin authentication.
- **Splash Screen:** An automatic 5-second cinematic entry. It features a layered fade-in for 'Welcome to TORA Luxury' followed by the mantra 'Unleash the Spirit of the Wild', underlined by a hyper-slim technical progress bar.
- **Footer:** A premium footer featuring a large, semi-transparent 'TORA' watermark behind the content. It must include social links, free delivery notices, and a bold, italic signature: **'By Aziz Ksila'**.

**Technical Specs:**
- Built with **Next.js 15**, **Tailwind CSS**, and **Framer Motion** for fluid, high-end transitions.
- Integrated **Firebase Firestore & Auth** for real-time product management and secure orders.
- Optimized for mobile-first luxury browsing."

---

## Project Structure
- `src/components/splash-screen.tsx`: The cinematic entry experience.
- `src/components/animated-background.tsx`: The "Tiger Stripe" dynamic light system.
- `src/components/tigra-logo.tsx`: The TORA serif brand mark with ink-stamp effect.
- `src/app/globals.css`: The "Tiger" theme color definitions and custom animations.
